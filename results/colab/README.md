# Colab benchmark outputs

Place files produced by `inference-benchmarks-colab.ipynb` here after you run it on Google Colab (GPU runtime), for example:

- `inference_benchmark_report.md`
- `inference_benchmark_results.csv`
- `benchmark_ttft_throughput.png`
- `benchmark_concurrency.png`
- `benchmark_comparison_bars.png`
- `benchmark_quantization_impact.png`

Download them from the Colab file browser (**folder icon** in the left sidebar) and commit if you want reproducible artifacts in git.

**Note:** Automated agents cannot execute Google Colab on your behalf; run the notebook in Colab, then add outputs to this directory and push.
